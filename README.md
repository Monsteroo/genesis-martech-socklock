# SockLock Creative Engine

## Що це

Генератор зображень для маркетологів і дизайнерів: опишіть, що потрібно, і за хвилину отримайте кілька варіантів, які можна одразу завантажити. Кадр можна анімувати у короткий відеокліп через HeyGen (див. «Анімація (HeyGen)»).

## Швидкий старт

1. Скопіюйте `.env.example` у `.env` і вставте ключ: `OPENAI_API_KEY=...` (ключ створюється на https://platform.openai.com/api-keys). Якщо хочете новішу модель, наприклад GPT Image 2.6, впишіть її в `OPENAI_IMAGE_MODEL`; точний ідентифікатор покаже `python3 -m engine models --filter image`.
2. Запустіть: `python3 -m engine web`
3. Відкрийте http://127.0.0.1:8780

Потрібен лише Python 3, нічого встановлювати не треба.

## Як користуватися

Сторінка має дві вкладки.

**Оригінали.** Опишіть зображення, оберіть кількість, формат і стиль, натисніть «Згенерувати». Картинки з'являються паралельно. Це нові зображення з нуля, за текстовим описом.

**Модифікації.** Оберіть один або кілька оригіналів, напишіть, що змінити (наприклад «вечірнє світло», можна взяти готову підказку), задайте кількість варіантів на кожен оригінал і запустіть. Під кожною модифікацією є «Ще схожі» з вибором кількості (1, 2, 4, 8, 12 або 24; за замовчуванням 4): ще варіанти тієї ж зміни, кожен з іншою підказкою (їх 24 різні); у вкладці «Оригінали» кількість теж до 24. Модифікацію можна змінювати далі кнопкою «Змінити →»: результат потрапляє в ту саму вкладку оригіналу з позначкою «з: …».

**Локалізація.** Кнопка «Локалізувати» на кожному оригіналі й кожній модифікації (а також «Локалізувати вибране» у вкладці «Модифікації») адаптує зображення під ринок: переклад підпису мовою ринку, місцеві деталі інтер'єру й реквізиту. Результат зберігається як звичайна модифікація в розділі «Локалізація: <країна>». Ринки: США, Велика Британія, Канада, Австралія (працюємо зараз), Німеччина, Франція, Іспанія (планується; це пропозиції, а не рішення). Список ринків редагується в одному місці: `MARKETS` у `engine/visuals.py` (ключ, назва, мова, локаль, статус `active`/`planned`). Підписи не англійською створює модель, тому їх обов'язково має перевірити носій мови до публікації.

**Анімація.** Третя вкладка (бета) перетворює оригінал або модифікацію на відеокліп через HeyGen; потрібен `HEYGEN_API_KEY`, за раз до 4 кліпів. Докладніше нижче. Зображень за один раз можна запустити до 24.

Модифікація бере саме картинку оригіналу як вхід (запит `images/edits`), тому зберігає його сюжет і змінює лише описане. Вона коштує дорожче за генерацію лише з тексту, бо вхідна картинка теж тарифікується токенами. Точні ціни дивіться в прайсі OpenAI: https://developers.openai.com/api/docs/pricing.

Позначте потрібні зображення, щоб завантажити їх одним ZIP-файлом або видалити. Усе згенероване зберігається в `library/gallery/` і лишається після перезапуску.

## Скільки це коштує

Кожне зображення оплачується з вашого ключа OpenAI. Ціни змінюються, актуальні дивіться на https://developers.openai.com/api/docs/pricing. Якщо вказати `OPENAI_IMAGE_PRICE_USD` (ціна одного зображення), сторінка покаже орієнтовну суму перед генерацією; для модифікацій реальна ціна вища за цю суму.

## Налаштування

Змінні читаються з `.env` у корені проєкту (або з середовища).

| Змінна | Що означає |
| --- | --- |
| `OPENAI_API_KEY` | Ваш ключ OpenAI (обов'язково, крім демо) |
| `OPENAI_IMAGE_MODEL` | Модель зображень (за замовчуванням `gpt-image-2`) |
| `OPENAI_IMAGE_QUALITY` | Якість: `low`, `medium`, `high` (за замовчуванням `medium`) |
| `OPENAI_IMAGE_SIZE` | Розмір за замовчуванням для команд CLI; на сторінці розмір задає вибраний формат |
| `IMAGE_WORKERS` | Скільки зображень генерується одночасно (за замовчуванням 4) |
| `OPENAI_IMAGE_PRICE_USD` | Ціна одного зображення для орієнтовної суми (необов'язково) |
| `OPENAI_TEXT_MODEL` | Текстова модель, потрібна лише для текстових команд CLI |
| `DEMO_IMAGE_DELAY` | Штучна затримка в демо-режимі, секунди (необов'язково) |
| `HEYGEN_API_KEY` | Ключ HeyGen для вкладки «Анімація» (без нього вкладка вимкнена) |
| `HEYGEN_TIMEOUT` | Скільки секунд чекати на один кліп (за замовчуванням 600, від 30 до 1800) |
| `HEYGEN_CLIP_PRICE_USD` | Ціна одного кліпу для орієнтовної суми (необов'язково, нічого не вигадуємо) |
| `VIDEO_WORKERS` | Скільки кліпів генерується одночасно (за замовчуванням 2, від 1 до 4) |
| `DEMO_VIDEO_DELAY` | Штучна затримка демо-відео, секунди (необов'язково) |

## Демо без ключа

    python3 -m engine --backend demo web

Замість справжніх зображень віддається заготовка `samples/demo/frame.png`, нічого не витрачається.

## Анімація (HeyGen)

Вкладка «Анімація» (бета) робить із нерухомого кадру короткий відеокліп через HeyGen Video (`heygen-video-1`, режим `image_to_video`). Кадром може бути оригінал або модифікація з галереї; вибраний кадр стає буквально першим кадром відео.

**Налаштування.** Створіть ключ на https://platform.heygen.com/api-keys, додайте в `.env` рядок `HEYGEN_API_KEY=ваш_ключ` і перезапустіть програму. Без ключа вкладка показує підказку й залишається вимкненою. Ключ читається лише зі змінних середовища (`.env`), не потрапляє в адреси, логи чи відповіді сторінки.

**Як користуватися.** Оберіть до 4 кадрів, за бажання опишіть рух (або натисніть підказку: «повільний наїзд», «паралакс» тощо), виберіть тривалість (5, 10 або 15 с) і натисніть «Створити анімацію». Кожен кадр дає один кліп. Кліпи лежать у `library/videos/`, групуються за кадром і рухом, їх можна завантажити, перемістити в кошик і відновити.

**Формат.** Відео має ті самі пропорції, що й кадр (вертикальне 9:16, квадрат 1:1, горизонтальне 16:9): для `image_to_video` HeyGen ігнорує `aspect_ratio` і йде за кадром. Інший формат спершу зробіть у «Модифікації». Роздільність 768p.

**Вартість.** Кліпи платні й повільні (зазвичай 1–3 хв на кліп). Ціну відео HeyGen ми НЕ перевіряли на офіційній сторінці: дивіться свій тариф і сторінку Usage у HeyGen. Якщо вказати `HEYGEN_CLIP_PRICE_USD`, сторінка покаже «≈ $X за кліп»; інакше напише «Ціна залежить від вашого тарифу HeyGen». Збій після оплати автоматично не повторюється, щоб не заплатити двічі.

**Обмеження.** Модель слабка на довгому тексті в кадрі, м'якому органічному русі (волосся, папір, пелюстки) і крупному плані рук; найнадійніші короткі статичні кадри. Посилання на готове відео підписане й тимчасове: програма одразу зберігає файл у `library/videos/`. Завантаження приймається лише з `https` та хостів `*.heygen.ai` / `*.heygen.com`, без перенаправлень, до 200 МБ. Кадри понад ~3,7 МБ завантажуються в HeyGen як asset, менші йдуть у запиті як base64.

**Демо без ключа.** `python3 -m engine --backend demo web`: замість відео віддається 1-секундна заготовка `samples/demo/clip.mp4`, нічого не витрачається.

**Живий тест.** `RUN_HEYGEN=1 python3 -m unittest tests.test_live.LiveHeyGen` створює ОДИН платний кліп 5 с у роздільності 480p. Звичайні тести нічого не викликають.

## Обмеження

- Модель може проігнорувати прохання «без тексту», тож перевіряйте результат на зайві написи й логотипи.
- Помилки 429 і вичерпаної квоти показуються як є; автоматичних повторів немає, бо кожен повтор це гроші.
- Текстові запити виконуються по одному, зображення генеруються паралельно.
- Ніколи не передавайте файл `.env` нікому і не додавайте його в git.
- Приклади в `samples/` синтетичні.

## Для розробника / домашка

Логіка сценаріїв (болі, концепти, скрипти, локалізація, збірка з блоків) лишилася в рушії та CLI для Homework #3 (MarTech). Команди `originals`, `modify`, `library`, `images` та інші описує `python3 -m engine --help`. Для текстових команд потрібні `OPENAI_API_KEY` і `OPENAI_TEXT_MODEL`; без ключа працює демо: `python3 -m engine --backend demo originals pains samples/pains.txt`.

Бекенд задає `--backend openai|demo` (або змінна `ENGINE_BACKEND`); за замовчуванням `openai`. Список моделей, доступних вашому ключу: `python3 -m engine models [--filter текст]`. Результати CLI пишуться в `out/`.

## Кошик

Кнопка «У кошик» (на плитці й у панелі вибору) нічого не стирає: зображення лише ховається з вкладок «Оригінали» й «Модифікації», а внизу на 8 секунд з'являється рядок «Переміщено в кошик · Відновити». Усе, що в кошику, видно у вкладці «Кошик»: звідти зображення повертаються на своє місце («Відновити») або стираються назавжди (двома натисканнями: «Видалити назавжди», «Очистити кошик»). Дочірні зображення прибраного оригіналу лишаються на місці з позначкою «в кошику», а працювати з такою батьківською картинкою (змінювати, локалізувати, «Ще схожі») можна лише після відновлення. У файлі метаданих це поле `trashed`.

## Локалізація підписів (Lingui)

Модель зображень помиляється в літерах не англійських підписів, тому підпис у цій частині малює не вона. Порядок такий: підпис (англійською, en-US) лежить у каталозі LinguiJS, сторінка бере з нього текст потрібного ринку й накладає його на зображення на canvas.

- Де: вкладка «Модифікації» → блок «Підписи для ринків (LinguiJS)». Підпис може мати ICU-змінні (`{name}`, `{count, plural, ...}`); їхні значення для попереднього перегляду й накладання задаються в полі «Значення змінних».
- «Перекласти для ринків» запускає AI-переклад на en-GB, en-CA, en-AU, de, fr, es. Сервер перевіряє, що плейсхолдери `{…}` вціліли, а SockLock і magnetic cuff не перекладені; невдалі переклади не зберігаються й позначаються «помилка». Результат має статус «машинний»; після вичитки натисніть «Затвердити» («перевірено»). Затверджені переклади повторний переклад не перезаписує. Переклад можна правити прямо в полі.
- «Локалізувати з підписом»: для кожного вибраного зображення й ринку сервер робить зображення без тексту (платний виклик, як звичайна локалізація, діють ті самі ліміти MAX_BATCH і «Ціна»), потім сторінка накладає підпис (місце: угорі, по центру, знизу; перенос рядків, авторозмір, контурна обводка) і зберігає PNG через `POST /api/gallery/overlay`. Готове зображення з'являється в розділі «Локалізація: …» оригіналу (поруч лежить версія без тексту); у ньому записані ринок, id підпису й локаль.
- Каталоги: `library/captions/<локаль>.json` (у git не потрапляють). Для власного конвеєра Lingui: `GET /api/captions.po?locale=de` (або кнопка «Завантажити .po») віддає стандартний gettext .po, де msgid = id підпису, msgstr = текст, у коментарях англійський оригінал і статус.
- Що вбудовано: справжній `@lingui/core` **6.10.1** (+ `@lingui/message-utils` для ICU) одним файлом `web/vendor/lingui-core.mjs`, без CDN. Звідки, контрольні суми й як зібрати заново: `web/vendor/README.md`, вихідні файли збірки в `vendor-src/lingui/`. Сторінка робить `i18n.load / activate / _` з цього файлу (у консолі доступний `i18n`).

Чесні обмеження: машинний переклад обов'язково вичитує людина; Lingui CLI (extract/compile) тут не використовується, каталоги ведуться напряму; власний AI-переклад у стеку SockLock (їхня Lingui-команда й автоматичний job) окремий від цього, тут лише демонстрація підходу й файли для їхнього конвеєра. Пропущені змінні в «Значеннях змінних» дадуть порожнє місце в підписі, тож перевіряйте перегляд перед запуском.
